# MosaicSync 1.33.0.88 publication notes

## GitHub release title

`MosaicSync 1.33.0.88`

## Firefox Add-ons — What's new

**A simpler shortcut editor**

The image controls are now easier to use. Automatic icon discovery is clearly indicated, the four image choices are neatly aligned, and entering a web image address happens in a separate window. Clear image is placed beneath the preview, and image Sync only appears for local uploads.

## Chrome Web Store — What's new

A cleaner shortcut editor with four evenly sized icon choices, a separate web image address window and a clearer automatic-discovery indicator. Image Sync is only shown for local uploads. Existing shortcuts and settings are preserved.

## GitHub release — changes since 1.33.0.87

- Automatic discovery indicated clearly; empty automatic preview is muted.
- Four equal artwork choice buttons on desktop and narrow windows.
- Web image URL input opens only on request in its own modal.
- Clear image is underneath the preview and returns to automatic mode.
- Sync this image appears only for a local file image; hidden options do not discard legacy synced images.
- All 34 language catalogs updated with the automatic-discovery label.
- No new permissions or telemetry; Sync, Recovery, favicon discovery and stored formats unchanged.

## Publication status

Candidate only until independent audit and six exact-commit GitHub checks complete. No remote changes were made while producing this candidate.
