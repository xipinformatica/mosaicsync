# MosaicSync 1.33.0.87 — Store changelogs

These notes cover changes since **1.33.0.86**. If a store is still serving an earlier version, include earlier applicable release notes as well.

## Firefox Add-ons — Release Notes

**What's new in 1.33.0.87**

The shortcut editor's four icon and image buttons now match in size and line up neatly, even when text wraps in different languages. The layout also adapts better to narrow windows. No translations were changed.

## Chrome Web Store — What's New

**Version 1.33.0.87**

A cleaner shortcut editor! Icon and image buttons now have matching sizes and better alignment across languages and window sizes. Your shortcuts and settings stay the same.

## GitHub Release — Changelog

### MosaicSync 1.33.0.87

**Shortcut editor layout polish**

- All four icon/image action buttons stretch to the same size, even when labels use different numbers of lines.
- Better narrow-window arrangement, with equal button sizes across both rows.
- The current translations for all 34 languages are unchanged.
- No changes to favicon discovery, shortcut naming, Sync, Recovery, permissions or storage.
