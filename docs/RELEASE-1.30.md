# MosaicSync 1.30 publication notes

## Public predecessor

MosaicSync 1.30 is the direct successor to 1.27.9.

## Mozilla changelog

Snow Leopard maintenance release: fixes a Firefox/Linux Settings paint failure, improves automatic favicon quality recovery, clarifies Sync source/receipt wording, strengthens complete-profile Sync recovery tests, removes obsolete Sync/CSS baggage, corrects stale localization copy, and adds Galician. No new permissions or schema/CSP changes.

## GitHub release title

`MosaicSync 1.30`

## GitHub release description

MosaicSync 1.30 continues the Snow Leopard cycle: no new product features, just a cleaner and more defensive engine. It hardens Settings rendering on Firefox/Linux, improves automatic favicon quality recovery, clarifies Sync source/receipt semantics, expands Sync recovery tests, removes obsolete Sync/CSS code, refreshes translations, and adds Galician. Existing permissions, schemas, CSP and security boundaries are unchanged.
