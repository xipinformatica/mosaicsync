Use MosaicSync on more than one computer?

To synchronize between Firefox computers, sign in to Firefox with the same account on each one. You can also use MosaicSync fully on just this computer.

Name this device Give this computer a name so you can see where synchronized changes came from.
Firefox handles synchronization in the background. Changes can take a few minutes to arrive on another computer. MosaicSync uses Mozilla's Firefox Sync instead of running its own server. That means no MosaicSync account, no MosaicSync cloud, no analytics and zero MosaicSync telemetry.
